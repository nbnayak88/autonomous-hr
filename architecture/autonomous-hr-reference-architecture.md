# Autonomous HR Reference Architecture

## Purpose

Define the master reference architecture for the Autonomous HR ecosystem and establish the common architectural language shared by the 12 HR streams.

## Architecture Layers

1. Business and HR Strategy
2. Capability and Value Streams
3. Business Architecture
4. Data Architecture
5. Application Architecture
6. Technology Architecture
7. AI Architecture
8. Integration Architecture
9. Security and Governance
10. Experience Architecture
11. Analytics and Intelligence
12. Ecosystem and Platforms

## Governing Approach

The architecture is capability-led, product-neutral, modular, API-oriented, data-centric, experience-led, secure by design, and designed for continuous evolution.

See the master repository README for the 12 domain streams.
